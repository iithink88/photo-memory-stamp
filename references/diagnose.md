# 分析 · 查表 · 修错

## 1. 照片类型判定

| 类型 | 特征 | 处理要点 |
|---|---|---|
| **A 建筑 / 地标** | 塔、桥、亭、城门、教堂、牌坊 | 甜区。抓轮廓线，砍掉所有表面装饰 |
| **B 街角旧物 / 招牌** | 老店招、路牌、邮筒、门牌、旧墙 | 甜区。**字就是锚点**，把字刻进印章 |
| **C 自然 / 风景** | 山水、海、日落、树 | 次甜区。抓一条线 + 一个圆 + 一片形，别指望刻"氛围" |
| **D 人物 / 肖像** | 单人、合影 | 冷区。刻脸几乎必败，改刻**姿态 + 随身物**（伞、自行车、帽子），或劝用户换照片 |
| **E 室内 / 静物** | 桌面、餐盘、书 | 可行。抓两三个物件的边缘关系 |
| **F 纯摆拍 / 商品图** | 白背景、崭新、居中 | **没有记忆可提**。直接告诉用户"这张印出来会像图标"，建议换有年代感/地方性的照片 |

判定完先下结论：这张值不值得印。**这套写法的门槛不在提示词，在选照片。**

## 2. 记忆锚点提炼四法

不要罗列"元素"，要挑"能被刻出来的差异"。

| 法 | 抓什么 | 例 |
|---|---|---|
| **结构** | 轮廓、拱、塔、飞檐、桁架 | 六角攒尖顶的翘角、单券拱洞 |
| **文字** | 招牌字、路牌、数字、招牌配色 | 「国营」二字的横竖比例 |
| **光** | 一条水平线、一个圆、一道光带 | 落日圆盘 + 海平线 |
| **姿态** | 树形、人物动作、物件倾斜 | 老槐树的分叉角度 |

**数量 3-5 个，宁少勿多。** 超过 5 个，印章必然糊成一团。挑不出 3 个 → 照片不合适，直说。

每条锚点都要能落到"线条/块面"上。写不出线条的锚点不是锚点，是形容词。

## 3. 外形查表

| 主体 | 外形 | 理由 |
|---|---|---|
| 塔、门、牌坊、立牌、竖招牌 | 竖长方形 | 贴合高宽比 |
| 街景、招牌、建筑群、静物 | 方形 / 圆角方形 | 中性，容错高 |
| 落日、水面、海岸、山脊 | 横长方形 / 椭圆 | 呼应水平线 |
| 器物、印章式徽记、圆形主体 | 圆 / 椭圆 | 呼应自身形状 |

外形写进提示词时用英文更准：`square` / `vertical rectangle` / `horizontal rectangle` / `rounded square` / `oval` / `circle`。

## 4. 配色规则

- 颜色只能来自 `stampkit.py palette` 的输出，**不许自己编**。
- 先看 `chromatic`（有彩色的主色），再看 `neutral`（灰调）。
- **1 色**：最像档案编号，克制到极致。适合单色建筑、剪影。
- **2 色**：最常用的高级解。主色 + 一个撞色或灰调。
- **3 色**：接近真实套色印刷，但**必须有主次**（大面积主色 + 两处小面积点缀），否则变杂。
- 从原图取的深绿、赭红、石灰蓝都很安全；**避开发光的高饱和色**（霓虹粉、荧光绿），印出来廉价。
- **浅色专色必须压深一档**。石头灰 `#D1D9EC` 这种明度 >85% 的颜色，叠在米白纸上几乎消失。取色后把明度压到 55-70% 再用（`#D1D9EC` → `#8E9BA6`）。这是实测踩过的坑。

## 5. 失败修法表（对症改一段，别整段重写）

| 症状 | 病灶 | 改法 |
|---|---|---|
| 印章像"缩小照片 + 滤镜" | 提炼段没起作用 | 把【提炼方式】整段提到提示词最前面；删掉提示词里所有"光影/层次/质感真实"类词；加一句"任何区域不得出现照片级明暗过渡" |
| 出了红色圆形公章 | 公章先验 | 把禁止段第 1 条挪到**正文第一句**；开头写 `Create an isolated vintage rubber stamp artwork (NOT a Chinese official seal)` |
| 印章太脏 / 破边 | 工艺段过头 | 删掉"局部缺墨、压力不均"，只留"边缘手工刻痕、套色 1px 错位" |
| 印章太平 / 像矢量图标 | 工艺感不足 | 加 `letterpress impression`、`slight ink grain`；`quality` 提到 `high` |
| 内部文字糊成鬼画符 | 模型写不好小字 | 删掉 `{INNER}`，写"不加任何文字"；文字全部交给合成阶段 |
| 锚点丢了一两个 | 信息过载 | 锚点砍到 3 个；把最重要的那个放第一位并写"必须最清楚" |
| 印章整体发灰、不精神 | 底不白 / 墨量映射偏 | 重新用 `background: transparent` 出一张；或合成时提高对比（脚本按底色调亮自动选择叠印方式） |
| **四周多出一圈边框线** | 提示词里写了"方形外廓 / 竖长方形外形" | **把外形那一整句删掉**，改写成"图案沿主体外缘自然结束，绝对不要加任何外框线、边框、画框、矩形包边"。模型对"外廓/方形"的默认反应就是画框 |
| **印章变成一幅完整的画** | 没限制数量 | 加"极度简化"：荷叶/窗格/瓦当各只刻几片，总笔画量要少，留白要多 |
| 荷叶、砖石糊成一块色块 | 块面描述不清 | 写"块面外廓是刻刀走出来的不规则起伏轮廓，带小缺口与毛边，不是矩形色块" |
| 照片主体被裁掉 | 构图与照片比例冲突 | 横图改 `--layout top`；或 `--share 0.62` 给照片更多空间 |
| 档案区太空 / 太挤 | 排版参数 | 空 → `--stamp-size 0.72`、`--margin 0.11`；挤 → `--stamp-size 0.56`、`--title-scale 0.038` |
| 标题拼错 / 关键词不是 3 个 | 合成参数错 | 检查 `--title`（自动转大写）与 `--keywords` 的 ` / ` 分隔 |

## 6. 九条自检（交付前逐条过）

1. 照片区与原图**逐像素一致**？（有任何重绘 = 不合格）
2. 印章是"刻"的，不是"缩"的？（有照片明暗层次 = 不合格）
3. 3 个记忆锚点都清楚可辨？
4. 套印色 ≤3 且来自原图？
5. 印章不是红色圆形公章？
6. 照片区顶格铺满，无白边、无边框、无投影？
7. 档案区大量留白，无胶带/贴纸/装饰边框/Logo/水印？
8. 标题 2-4 个英文单词、全大写、拼写正确？关键词恰好 3 个、`a / b / c` 格式？
9. 整张图第一眼看到的是印章（而不是照片）？

第 1、2、9 条任一不合格 → 重做，不要交付。
