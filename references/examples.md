# 案例与调参

## 案例 1 · 荷塘园林（实测）

**原图**：横版 625×401，前景满塘荷叶与荷苞，右后一座重檐六角亭，左后一座单拱石桥，背景有白色居民楼和电线。

**分析卡**

| 槽 | 值 |
|---|---|
| 主体 | 中国园林荷塘：重檐六角亭 + 单拱石桥 + 荷叶与荷苞 |
| 锚点 1 | 六角攒尖顶向上翘起的檐角轮廓 |
| 锚点 2 | 石桥中央的单券拱洞 |
| 锚点 3 | 竖立的荷苞与圆形大荷叶 |
| 删除 | 白色居民楼、电线、远处游人；荷叶只留三片大的 |
| 外形 | 不加外框，图案沿主体外缘自然结束 |
| 套印色 | `#2C5813` 深荷叶绿 / `#C9748C` 荷花粉 / `#8E9BA6` 石桥青灰 |
| 标题 | `LOTUS POND` |
| 关键词 | `pavilion / arch / lotus` |
| 版式 | 横版照片 → `--layout auto` 走上下版，`--share 0.54` |

**三次迭代的真实差别**

| 版本 | 提示词差异 | 结果 |
|---|---|---|
| v1 | 只说"方形外廓"，没写"荷叶只留几片" | 荷叶糊成一块，绿色变成**硬边矩形色块**，浅灰桥几乎看不见 |
| v2 | 加了"块面外廓要刻刀起伏，不是矩形"，但没限制数量 | 质感极好，但荷叶铺满整张，**违背简化** |
| v3 | 加了"荷叶只刻三片"，又写"方形印章外廓" | 简化到位，但模型把"外廓"理解成**画框**，四周多了一圈边框 |
| **v4** | 删掉"方形外廓"这一句，改写成"**绝对不要加任何外框线、边框、画框**" | 通过：无边框、三片叶、刻痕清楚、三色干净 |

**结论写进母版**：`方形` 这个词不能出现在"外形"槽里。模型对"外廓/方形"的默认反应是画一个框。要方形感就靠画布本身，不要靠描述。

**同图两版版式**

| 版式 | 效果 | 判定 |
|---|---|---|
| `top`（上下） | 照片完整、信息量大、印章在下方独立呼吸 | **横版照片默认走这个** |
| `left`（左右） | 照片被竖切成窄条，亭子和桥被裁掉边缘 | 横版照片慎用，会丢主体 |

## 案例 2 · 仰视斜拉桥（方法推演）

- 锚点：塔柱的倒三角轮廓 / 拉索的直线束 / 赭红塔身与天空灰的撞色
- 外形：竖长方形（贴合塔的高宽比）——**注意**：不要写"竖长方形外框"，写"图案沿塔与拉索的外缘自然结束"
- 套印色：`#B4472A` / `#8E9BA6`　标题 `ORANGE PYLON`　关键词 `bridge / cable / sky`
- 版式：竖版照片 → `--layout left --share 0.58`

## 案例 3 · 日落跨海桥（方法推演）

- 锚点：一条水平线 / 两座塔的剪影 / 落日那个圆
- 外形：横长方形或椭圆（呼应水平线），负空间要留足，别把海填满
- 套印色：`#C4501F` / `#2E2A33`　标题 `SUNSET CROSSING`　关键词 `sea / dusk / cable`
- 版式：横版 → 上下版；落日照片本身很空，`--share` 可压到 0.50 让印章区更大

## 单变量调参法

一次只改一个量，改完对比。改动顺序建议：

1. **锚点**（决定成败）→ 先保证 3 个锚点都在，且第一个最清楚
2. **色数**（1 ↔ 2 ↔ 3）→ 先试 2 色，最稳
3. **简化度**（叶/窗/瓦当的数量）→ 出现"糊成一团"就减数量，出现"太像图标"就加一道结构线
4. **版式占比** `--share` 0.50 / 0.54 / 0.58 → 看照片重要还是印章重要
5. **画幅** 3:4 / 4:5 / 1:1 → 只影响发布场景，不影响印章本身

对比命令：

```bash
"$PY" "$SK" sheet out/ --out out/compare.jpg --height 700
```

## 常见审美的三个直觉

- **空得多才像档案**。档案卡的贵气来自留白，别急着把印章放大。
- **色少才高级**。1-2 色几乎不会错，3 色必须有一色只占 5% 面积。
- **错位才像手工**。`--rotate -1.2` 默认那 1 度多，是"手工压印"的关键；要绝对工整就 `--rotate 0`，但会显得像印刷品而非印章。
